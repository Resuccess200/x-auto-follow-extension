# X 自动互关与拓客助手 (X Auto Follow & Growth Assistant)

一款适用于 Google Chrome 与 Microsoft Edge 的轻量级本地化浏览器扩展。专为在 X (Twitter) 粉丝与关注列表页设计，支持一键安全回关粉丝，以及通过“粉丝/关注差值”智能过滤蓝V用户进行精准拓客。

## 核心特性

### 🛡️ 极速安全防护 (安全优先)
- **极速风控熔断**：内置毫秒级文案侦测系统，涵盖多语言（如“速度限制”、“rate limit”等）。一旦页面出现任何限制弹窗或红色警告，脚本将在 0.1 秒内瞬间停机，保护账号安全。
- **静默限速检测**：新增状态校验防呆机制。若点击“关注”后规定时间内按钮未产生变化，自动判定为被平台“静默限速”并立刻切断运行。
- **战术拟人微休眠**：每成功关注 8~12 人，强制触发 25~45 秒的深度休眠，完美模拟人类操作节奏。
- **双滑动窗口限流**：拒绝无脑高频操作，底层的限流器绝对服从用户设定的时间窗口，防止触发高频风控。

### ⚙️ 自定义运行参数
- **动态限速面板**：在控制面板上，用户可自行输入“20秒内最大关注数”与“60秒内最大关注数”（默认安全值为 3 和 8），配置实时生效并自动持久化保存至浏览器本地。
- **蓝V粉关差值过滤**：在他人列表中运行时，自动透视悬浮卡片获取数据。支持自定义“粉丝与关注数的最大差值”（如 ≤150），仅关注高活跃度、非互刷的真实蓝V账户。
- **纯本地运行**：纯原生前端脚本，无任何外部接口调用，不收集、不上传任何用户隐私数据。

### 📊 智能监控与交互
- **动态身份识别**：毫秒级识别当前登录账号，仅在符合规则的页面唤起面板。完美兼容 X 单页应用（SPA）的账号切换。
- **实时统计面板**：直观显示当前登录用户名、已回关/关注计数及本次运行时间，支持一键清零重置。
- **双重去重机制**：采用 `WeakSet` 记录已处理过的按钮，避免因列表刷新导致的重复点击，并通过模块特征识别自动避开侧边栏“推荐关注”干扰。

## 安装步骤（CRX 方式）

1. 下载项目 Release 中的 `x-auto-follow-assistant.crx` 文件。
2. 打开 Chromium 内核浏览器（Chrome / Edge）并进入扩展管理页面：
   - **Chrome**: 在地址栏输入 `chrome://extensions/` 并回车
   - **Edge**: 在地址栏输入 `edge://extensions/` 并回车
3. 在页面右上角**开启“开发者模式” (Developer mode)**。
4. 打开文件管理器，将下载的 `.crx` 文件直接**拖拽**至浏览器的扩展管理页面中。
5. 在弹出的权限确认提示框中点击 **“添加扩展程序”** 即可完成安装。

> **安装提示**：若浏览器拦截第三方 CRX 文件的拖拽安装，可将 `.crx` 文件后缀名重命名为 `.zip`（或直接使用解压软件解压至单独文件夹），随后在扩展管理页面点击 **“加载已解压的扩展程序”** 并选择解压后的文件夹载入使用。

## 使用说明

1. 在浏览器中访问 X (Twitter) 并登录你的账号。
2. 进入目标列表页面：
   - **互关模式**（回关粉丝）：`https://x.com/<你的用户名>/followers` 或 `verified_followers`
   - **拓客模式**（挖掘蓝V）：`https://x.com/<目标用户名>/followers` 或 `following`
3. 页面右下角将自动唤起控制面板。
4. **配置参数**：
   - 根据账号权重，在“限速”框中输入安全数值（建议保持默认）。
   - 在拓客模式下，可设置“蓝V粉关最大差值”，以过滤掉刷粉号。
5. 点击 **“开始运行”**，脚本将自动扫描列表、执行过滤逻辑并发起关注；点击 **“停止”** 可随时中止运行。
