# X 自动互关助手 (X Auto Follow Assistant)

一款适用于 Google Chrome 与 Microsoft Edge 的轻量级本地化浏览器扩展，专为在 X (Twitter) 粉丝列表页快速回关未关注用户而设计。

## 功能特性

- **严格本地运行**：纯原生前端脚本，无任何外部接口调用，不收集或上传任何用户数据。
- **动态身份识别**：自动识别当前登录账号，仅在属于本人的粉丝列表页（`/followers` 与 `/verified_followers`）激活控制面板，防止误操作。
- **安全频率限制**：内置双滑动窗口限流机制（20 秒内最多 3 次，60 秒内最多 10 次），模拟人工间隔，降低触发平台风控的风险。
- **实时运行统计**：面板显示当前登录用户名、已回关计数及本次运行时间，支持计时自动清零与计数手动重置。

## 安装步骤（CRX 方式）

1. 下载项目 Release 中的 `x-auto-follow-assistant.crx` 文件。
2. 打开 Chromium 内核浏览器（Chrome / Edge）并进入扩展管理页面：
   - **Chrome**: 在地址栏输入 `chrome://extensions/` 并回车
   - **Edge**: 在地址栏输入 `edge://extensions/` 并回车
3. 在页面右上角**开启“开发者模式” (Developer mode)**。
4. 打开文件管理器，将下载的 `.crx` 文件直接**拖拽**至浏览器的扩展管理页面中。
5. 在弹出的权限确认提示框中点击 **“添加扩展程序”** 即可完成安装。

> **安装提示**：若浏览器拦截第三方 CRX 文件的拖拽安装，可将 `.crx` 文件后缀名重命名为 `.zip`（或直接使用解压软件解压至单独文件夹），随后在扩展管理页面点击 **“加载已解压的扩展程序”** 并选择解压后的文件夹载入使用。

## 使用说明

1. 在浏览器中访问 X (Twitter) 并登录你的账号。
2. 进入本人的粉丝列表页面：
   - `https://x.com/<你的用户名>/followers` 或
   - `https://x.com/<你的用户名>/verified_followers`
3. 页面右下角将自动唤起控制面板。
4. 点击 **“开始运行”**，插件将自动检索未回关的用户并执行关注操作；点击 **“停止”** 可随时中止运行并重置计时。
